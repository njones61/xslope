# Limit Equilibrium Benchmarks

XSLOPE's limit-equilibrium verification is organized around the two vendor
verification-manual corpora, so individual LEM benchmarks are documented once,
on the page whose manual defines them:

- **[Rocscience Slide2 corpus](rocscience.md)** — the ACADS simple homogeneous
  slope lives under [VP1](rocscience.md#vp1) and the Arai & Tagyo homogeneous
  slope under [VP14](rocscience.md#vp14), each with the full seven-method
  comparison table, input file, and figures.
- **[GeoStudio SLOPE/W corpus](geostudio.md)** — the ACADS weak-layer
  non-circular benchmark is written up under
  [its problem details](geostudio.md#acads-weak-layer).

Sample problems that are not verification benchmarks remain in the
[LEM sample problems](../lem/samples.md).
